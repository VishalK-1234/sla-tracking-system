# 3-Minute Demo Script

1. **0:00–0:25 — Problem and policy:** explain priority targets (High 24h, Medium 48h, Low 72h), UTC calendar hours, weekends included.
2. **0:25–1:00 — Dashboard:** show total/open/in-progress/resolved/overdue counts and SLA compliance.
3. **1:00–1:40 — Create ticket:** create a High-priority ticket and show its automatically assigned due date.
4. **1:40–2:15 — Overdue behavior:** point out seeded overdue ticket; explain that overdue is derived from current time and excludes completed tickets.
5. **2:15–2:40 — Status update:** resolve a ticket and show dashboard metrics refresh.
6. **2:40–3:00 — Engineering evidence:** show spec, tests, Playwright scenario, and explain AI-generated changes were reviewed and tested.
