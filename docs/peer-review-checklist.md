# Peer Review Checklist

- [ ] SLA targets match the approved specification.
- [ ] UTC timestamps are used consistently.
- [ ] Weekend/calendar-hour behavior is tested.
- [ ] Overdue is derived, not manually editable.
- [ ] Resolved and Closed tickets are excluded from overdue counts.
- [ ] Priority/status filters and search work together.
- [ ] Invalid ticket input is rejected by the API.
- [ ] UI handles loading, errors, and empty results.
- [ ] Unit, API, frontend, and E2E tests have been run.
- [ ] AI-generated code has been reviewed and the AI usage note is accurate.
- [ ] No production secrets or real personal data are included.
